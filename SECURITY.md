# Security Policy

## Supported Versions

The project is currently in active development. Only the latest release receives security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ Yes     |
| < 0.1   | ❌ No      |

## Platform Support

The latest release has been tested on:

| Platform | Status                                        |
| -------- | --------------------------------------------- |
| Linux    | ✅ Supported                                   |
| Android  | ✅ Supported (demo APK)                        |
| Windows  | ⚠️ Expected to work but not officially tested |
| macOS    | ❌ Not tested                                  |
| iOS      | ❌ Not supported                               |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a **GitHub Issue** with the **Security** label.

Please include:

* A description of the vulnerability.
* Steps to reproduce the issue.
* The affected version.
* Your operating system.
* Any relevant logs or screenshots.

If possible, include a minimal example demonstrating the issue.

Please do **not** publicly disclose vulnerabilities that could put users at immediate risk until they have been reviewed.

Security reports will be reviewed as time permits. As this is currently a solo-maintained project, response times may vary.

Thank you for helping improve the security of this project.
