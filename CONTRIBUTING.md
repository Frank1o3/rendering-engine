# Contributing

Thank you for your interest in contributing to this project!

## Reporting Bugs

If you find a bug, please open a GitHub Issue and include:

* A clear description of the problem.
* Steps to reproduce it.
* Your operating system.
* Rust version (`rustc --version`).
* Any relevant logs or screenshots.

## Suggesting Features

Feature requests are welcome. Please explain:

* What problem the feature solves.
* How you expect it to work.
* Any alternatives you've considered.

## Pull Requests

Before submitting a pull request:

* Ensure the project builds successfully.
* Follow the existing code style.
* Keep changes focused on a single feature or fix.
* Update documentation if your changes affect users.

Large changes should be discussed in an issue before implementation.

## Code Style

* Use `cargo fmt` before committing.
* Run `cargo clippy` when possible.
* Prefer clear, readable code over clever solutions.
* Document public APIs where appropriate.

## Questions

If you're unsure about something, feel free to open an issue before starting work.

Thank you for helping improve the project!
